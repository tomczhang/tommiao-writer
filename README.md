# tommiao-writer

汤姆喵公众号长文写作 skill。

公众号名称是"汤姆喵的奇妙旅行"，欢迎关注。

这个 skill 用来帮助生成、续写、改写汤姆喵风格的公众号文章，重点服务于投资反思、投资体系构建、AI 工具实战、读后感延展、人生阶段总结和公共议题延展。

它的核心不是模仿某个外部作者，而是沉淀汤姆喵自己的近期主风格：

一个资深程序猿和重度 AI 使用者，用真实试错、工程化拆解和费曼式反思，尝试把投资、AI、人生选择权讲成普通人能理解、能执行、能共鸣的体系化文章。

## 适用场景

当你需要处理这些任务时使用：

- 写公众号文章
- 续写或扩写文章草稿
- 按汤姆喵风格改写素材
- 写投资反思、现金流、仓位管理、纪律、选择权相关内容
- 写 AI 工具、AI 分身、Agent、Claude Code、LangChain 相关内容
- 从机哥、金渐成、巴菲特、段永平、书籍或外部文章延展自己的理解
- 把一个公共议题拉回到普通人的处境和行动选择

## 里程碑

### 第一阶段：蒸馏自卡兹克 skill（2026 年 5 月初）

最初版本基于卡兹克 skill 框架做蒸馏，用槽位思维（六种文章原型 + 标准结构 / 前慢后重 1/3 节奏 / 四层自检 L1-L4 / 写作流程九步）来约束输出。

能产出基本可读的文章，但**有挥之不去的 AI 味**——文章读起来像"通过考试的产品"，工整但缺人味。

### 第二阶段：从 focus 防止 AI 味，转向 focus 真人写作（2026 年 5 月 17-18 日）

诊断出根逻辑错误：「凑槽子反 AI」本质还是槽位思维——AI 一旦掉进槽位思维，无论槽里装的是 AI 套路还是反 AI 套路，都还是 AI 味。

转向「加法」路线：

- **锚定真人样本** — 把汤姆喵纯手写原文和对话框非写作语料作为最高权重锚点
- **真人写作公理替代槽位规则** — 14 条公理（开头能拍照 / 情绪身体化 / 排比有重复词头 / 反思后置 / 比喻要狠……）取代「标准结构」
- **第一原则** — 句式服务于内容，每写一句先问"这是为了说清楚，还是为了好看"
- **人补充机制** — 涉及具体依据 / 例子 / 数字时，AI 必须停下来问作者，不能自己编
- **跨模型共性禁项** — 吸收 Humanizer-zh / 维基百科 AI Cleanup 的发现，禁掉跨模型 AI 共性兜底（两项优于三项 / 虚假范围 / 同义词循环 / 过度限定）

SKILL.md 从 355 行重构为 277 行，砍掉「标准结构」「四层自检」等槽位载体。

## 文件说明

- `SKILL.md`：主规则。第一原则 + 核心人格 + 前置三问 + 14 条真人写作公理 + 死禁项 + 人补充机制 + 写作流程。
- `references/chat_voice.md`：汤姆喵在对话框里的非写作姿态语言。最干净的语调锚点。
- `references/full_articles/`：完整真人原文（手写）+ 按 skill 跑出来的验证样本。in-context 浸泡素材。
- `references/banned_patterns.md`：禁止写法和反例。第 11 节是跨模型 AI 共性句式禁项。
- `references/style_examples.md`：汤姆喵历史文章的风格片段索引。
- `references/article_archetypes.md`：文章原型描述。**参考用，不要当模板套**——会触发槽位思维。
- `references/inspiration_patterns.md`：从外部作者吸收的写作机制。

## 核心原则

- **句式服务于内容**——不是反过来。
- 开头第一句必须能拍照（具体到时间 + 动作 + 画面 + 心理反应）。
- 情绪用身体性描述（咯噔 / 想笑 / 红着脸），不用抽象内省（那一下我警觉 / 我意识到）。
- 段落长短按重要程度分配，不追求均匀。
- 排比要有重复词头，且两项优于三项。
- 反思后置——只能在文章后 1/3，且要带具体画面。
- 比喻要狠，安全比喻 = 死比喻。
- 借外部作者的机制，不借外部作者的人设。

## 维护说明

这个 skill 会随着汤姆喵新的文章和人工修改反馈持续迭代。

如果某次生成内容被人工大幅修改，优先把修改背后的规则沉淀回：

- 句式 / 用词 / 节奏问题 → `references/banned_patterns.md` 或 SKILL.md 的公理
- 真人原话 → `references/chat_voice.md`
- 完整可参考样本 → `references/full_articles/`
